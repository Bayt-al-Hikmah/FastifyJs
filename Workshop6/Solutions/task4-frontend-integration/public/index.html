    Under the hood

    What this page teaches

    Every control here is an ordinary browser API talking to a separate Fastify service.

    • Fetch + response.ok The shared helper checks the HTTP status instead of trusting the Promise to reject, and renders JSON or null for 204 responses.
    • DOM updates Cards, lists, and dialogs are built with textContent, so API text is never interpreted as markup.
    • Validation errors Forms use novalidate on purpose: the API's errors array drives the messages and highlights the right field.
    • Ownership Edit, publish, delete, and cover controls only appear for events owned by the signed-in user.
    • FormData The browser sets the multipart boundary. A private API endpoint streams the cover back after checking the token.
    • CORS This page runs on port 5173 and the API on port 3000. The API must allow this origin explicitly.
    Troubleshooting If the gallery shows a connection error, start community-events-api first with FRONTEND_ORIGIN=http://127.0.0.1:5173.
